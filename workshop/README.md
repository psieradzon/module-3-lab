# Modul 3: Arbeiten mit GitHub Copilot und Coding Agents

In diesem Lab lernst du GitHub Copilot nicht als Codegenerator, sondern als Zusammenarbeitspartner kennen. Du startest mit dem Verstehen einer unbekannten Anwendung und übergibst dem Agenten anschließend zunehmend selbstständigere Aufgaben.

Der Pflichtpfad ist auf einen Halbtag von 9:00 bis 13:00 Uhr ausgelegt, inklusive zweier Pausen von je 10 Minuten.

## Lernziele

Nach dem Lab kannst du:

- Ask, Plan und Agent passend zur Aufgabe auswählen,
- auffindbaren Kontext vom Agenten selbst suchen lassen,
- fachlichen Kontext und Erfolgskriterien gezielt ergänzen,
- Bugs und Features agentisch bearbeiten,
- Änderungen mit Tests, Anwendung und Diff verifizieren,
- Ergebnisse aus Entwickler- und PM-Perspektive bewerten.

## Arbeitsweise

Arbeite auf einem eigenen Branch und committe sinnvolle Zwischenstände. Prüfe Agentenänderungen, bevor du sie übernimmst. Ein grüner Testlauf ist wichtig, ersetzt aber nicht die Prüfung des fachlichen Verhaltens.

> [!IMPORTANT]
> Die Aufgaben nennen bewusst keine Lösungsdateien oder Funktionen. Das Finden des relevanten technischen Kontexts ist Teil des Lernziels.
